# Medical Management System (FHI-IMAPL 2025)

Toto je jednoduchá konzolová aplikácia na správu lekárskej praxe, vyvinutá v rámci predmetu **Mobilné a Internetové Aplikácie (IMAPL)**. Systém je postavený na TypeScript-e a beží na platforme Node.js. Je navrhnutý ako základný projekt, ktorý je možné v budúcnosti rozšíriť o databázu, REST API a webové rozhranie.

Systém je prispôsobený pre slovenské prostredie, vrátane špecifických validačných pravidiel pre dáta ako telefónne čísla a podpory slovenských diakritických znamienok v menách.

## Kľúčové funkcie

-   **Správa pacientov**: Vytváranie, prehliadanie a vyhľadávanie pacientov.
-   **Správa lekárov**: Pridávanie a zobrazenie zoznamu lekárov v systéme.
-   **Plánovanie termínov**: Vytváranie, aktualizácia, rušenie a prehliadanie termínov.
-   **Zdravotné záznamy**: Pridávanie a prehliadanie zdravotných záznamov pacientov, vrátane diagnóz, liečby a poznámok.
-   **Validácia dát**: Prísna, vstavaná validácia pre všetky dáta na zabezpečenie ich integrity (napr. formát mena, telefónne čísla, dátumy).
